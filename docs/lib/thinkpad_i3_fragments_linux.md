# thinkpad_i3_fragments_linux.sh

Biblioteca común para publicar bloques administrados de i3 como fragmentos independientes. No se ejecuta directamente: los instaladores Rafex la cargan junto con el guard de configuración.

- **Ruta:** `scripts/lib/thinkpad_i3_fragments_linux.sh`
- **SO requerido:** Linux
- **Dependencias:** Bash, `awk`, `cmp`, `cp`, `mktemp`, `mv`, `readlink`

## Requisitos

Debe cargarse mediante `source` desde un script del perfil. La configuración de i3 debe tener el encabezado generado por Rafex para activar este modo.

## Uso

Los instaladores llaman internamente a `rafex_i3_fragment_replace`. El árbol de estado se crea en:

```text
~/.local/state/rafex/config-generated/thinkpad/i3/
├── base.conf
├── config
└── fragments/*.conf
```

El archivo estándar `~/.config/i3/config` puede ser un enlace al archivo compuesto. Cada cambio reemplaza únicamente el fragmento de su propietario y recompone el archivo de forma atómica.

## Variables de entorno

| Variable | Descripción |
|---|---|
| `RAFEX_I3_FRAGMENT_ROOT` | Sobrescribe el árbol de fragmentos; se usa para pruebas controladas. |
| `XDG_STATE_HOME` | Define la raíz de estado cuando no se especifica `RAFEX_I3_FRAGMENT_ROOT`. |

## Ejemplos

Forma recomendada, mediante un instalador:

```bash
just install-conky --apply
```

Comprobar el resultado compuesto:

```bash
grep -n 'Generated by rafex i3 fragment composer' ~/.config/i3/config
find ~/.local/state/rafex/config-generated/thinkpad/i3/fragments -maxdepth 1 -type f -print
```

No existe modo `.env` ni modo legacy directo para esta biblioteca.

## Protecciones de seguridad

- Solo reconoce marcadores Rafex previamente definidos.
- Conserva el contenido no administrado en `base.conf`.
- Publica con archivo temporal y `mv` atómico.
- No usa `sudo`, no ejecuta comandos de i3 y no reinicia la sesión.
- No se activa hasta que el publicador central haya compuesto la configuración.

## Fallos conocidos

### `i3 no usa el archivo compuesto`

**Causa:** El archivo estándar todavía es manual o no contiene el encabezado de composición.

**Solución:** Ejecuta primero `just rafex-config --adopt` después de revisar el plan y los respaldos. No reemplaces manualmente el archivo.

### `el fragmento no se actualiza`

**Causa:** El marcador del bloque no pertenece al catálogo administrado.

**Solución:** Corrige el marcador del instalador o registra el nuevo recurso en `thinkpad-ownership.tsv`; no agregues una segunda edición incremental.
